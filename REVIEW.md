# 1. Список найденных проблем
1. Строка 34: загрузка всех записей time_entries без фильтра. При росте БД – переполнение памяти и падение. Исправление: добавить фильтр по году и месяцу.
2. Строка 42: синхронное .Result у FirstOrDefaultAsync() внутри асинхронного метода. Блокировка потоков, риск дедлока. Исправление: асинхронно загрузить всех сотрудников и проекты до цикла, убрать .Result.
3. Строка 44: выбор первой ставки без учёта даты (From). Неверный расчёт за прошлые периоды. Исправление: выбирать ставку, действующую на дату записи.
4. Строка 74: деление на Budget без проверки на ноль. DivideByZeroException для проектов с нулевым бюджетом. Исправление: проверять Budget != 0.
5. Строки 42–52: отсутствие проверок на null для employee, project, Rates. NullReferenceException при отсутствии данных. Исправление: добавить проверки, пропускать записи.
6. Использование double для денег (Amount, Budget, Rate.Value) и часов. Погрешности округления. Исправление: заменить на decimal.
7. N+1 запросов к employees и projects в цикле. Много сетевых вызовов, замедление. Исправление: загрузить все нужные записи одним запросом через IN, построить словари.
8. Расчёт в памяти, а не в БД. Рост трафика и времени при увеличении данных. Исправление: использовать агрегационный конвейер MongoDB ($match, $lookup, $group, $project).
